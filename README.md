# Week 7

Java lab exercises for Week 7 covering packages and multithreading.

### Programs:
- `CollegeManagement.java` (using `student` and `course` packages)
- `HospitalManagement.java` (using `doctor` and `patient` packages)
- `OnlineExam.java`
- `BankingConcurrent.java`
- `TrafficManagement.java`

### How to Run:
```bash
javac <filename>.java
java <classname>
```
