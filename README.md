# Java Programming - Week 1

This branch contains the solutions for the Week 1 tutorial session.

## Programs Included:

### Core Concepts
* **Program 1 (sum.java):** Addition of Two Numbers - Reads two integers and displays their sum. (Variables, input/output)
* **Program 2 (even.java):** Even or Odd - Reads an integer and determines whether it is even or odd. (Conditional statements)
* **Program 3 (largest.java):** Largest of Three Numbers - Finds the largest among three input values. (Nested if statements)
* **Program 4 (factorial.java):** Factorial of a Number - Computes the factorial of a positive integer. (Loops)
* **Program 5 (multiply.java):** Multiplication Table - Displays the multiplication table for a given number (1 to 10). (for loop)

### Challenge Questions
* **Challenge 1 (reverse.java):** Reverse a number.
* **Challenge 2 (palindrome.java):** Check whether a number is a palindrome.
* **Challenge 3 (fibonacci.java):** Generate the Fibonacci series.
* **Challenge 4 (prime.java):** Check whether a number is prime.
* **Challenge 5 (sumd.java):** Calculate the sum of digits of a number.

## How to Run
1. Compile the program: `javac <filename>.java`
2. Run the program: `java <classname>`
