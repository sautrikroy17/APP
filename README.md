# Java Programming - Week 2

This branch contains the Object-Oriented Programming (OOP) solutions for the Week 2 tutorial session.

## Programs Included:

1. **Student Details (stud.java / student.java):** Class to store and display student information (name, roll number, department).
2. **Library Books (book.java):** Class to keep track of books, storing title, author, and price, with details display.
3. **Student Registration System (student1.java):** Basic student details tracking system.
4. **Floor Area Calculation (rectangle.java):** Class to store length and breadth, then calculate and display floor area.
5. **Multiple Students Record (student.java):** Handling multiple student objects with different names and ages.
6. **Employee Management System (employee.java):** System to maintain and display details for multiple employee records.
7. **Marks Calculation (marks.java):** Automates calculation of total and average marks for a student based on three subjects.
8. **Temperature Conversion (temperature.java):** Converts and displays temperature from Celsius to Fahrenheit.

## How to Run
1. Compile the program: `javac <filename>.java`
2. Run the program: `java <classname>`
