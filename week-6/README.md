# Week 6

Java OOP programs for Week 6 tutorial covering polymorphism, interfaces, and packages.

### Programs:
- `VehicleRental.java`
- `PaymentApp.java`
- `BankingSecurity.java`
- `DocumentManagement.java`
- `CollegeManagement.java` (using `student` and `course` packages)
- `OnlineBanking.java` (using `banking.account` and `banking.payment` packages)

### How to Run:
```bash
javac <filename>.java
java <classname>
```
